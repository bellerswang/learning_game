# 🌈 Magic Learning Toolbox

A collection of interactive web-based games designed for learning and fun!

## 🚀 How to Put This on the Internet (GitHub Pages)

To make these games accessible on mobile devices, you first need to turn on **GitHub Pages**:

1.  Go to your GitHub repository: [https://github.com/bellerswang/learning_game](https://github.com/bellerswang/learning_game)
2.  Click on the **Settings** tab (top right).
3.  On the left sidebar, click **Pages** (under the "Code and automation" section).
4.  Under **Build and deployment** / **Source**, select **Deploy from a branch**.
5.  Under **Branch**, select **main** and folder **/(root)**.
6.  Click **Save**.

Wait about 1-2 minutes. Refresh the page, and you will see your live URL at the top (e.g., `https://bellerswang.github.io/learning_game/`).

---

## 📱 How to Install on mobile devices (iPhone/iPad)

Once the website is live, follow these steps to install it as a full-screen "App" on the Home Screen:

1.  **Open Safari** 🧭 on the iPhone/iPad.
2.  Go to your new website URL (from the step above).
3.  Tap the **Share Button** (the square box with an arrow pointing up 📤) at the bottom of the screen.
4.  Scroll down and tap **"Add to Home Screen"** ➕.
5.  (Optional) Rename it to "Magic Games" if you want.
6.  Tap **Add** in the top right corner.

🎉 **Done!**
Now there is a new icon on the Home Screen. When kids tap it, the games will open full-screen, just like a real app from the App Store!
